GPX Layer & Symbol Studio v2.4

Ebenen, Symbole & Fund-Markierungen für OsmAnd aufbereiten

📖 Kurzanleitung: GitHub aktualisieren & in OsmAnd als Favoriten importieren Aufklappen ▼
1. Neue Version auf GitHub hochladen:
  1. Öffne dein Repository auf github.com (z. B. oli20021978/landkreis...).
  2. Tippe auf die bestehende Datei gpx.html → oben rechts auf das Stift-Symbol (Edit) (oder Add file → Upload files, um sie zu überschreiben).
  3. Füge den neuen Code ein und bestätige unten mit Commit changes.
  4. Warte ca. 30–60 Sekunden und lade die Webseite neu. Kontrolle: Oben im Titel steht jetzt das grüne Badge v2.4.
2. GPX-Ebenen im Studio einstellen:
  1. Lade deine GPX- oder ZIP-Datei in Schritt 1.
  2. Deaktiviere unter Schritt 2 nicht benötigte Zusatzwegpunkte (z. B. Reference Point, Virtual Stage) über den Schalter Aktiv / Aus.
  3. Passe Ebenenname, Form, Farbe und Icon an und tippe unten auf „Kombinierte GPX für OsmAnd herunterladen (Favoriten-Ebenen)“.
3. Wichtig – In OsmAnd „Als Favoriten“ (NICHT als Track!) importieren:
  1. Tippe im Android-Dateimanager oder in den Browser-Downloads auf osmand_geocaching_ebenen.gpx → Öffnen mit OsmAnd.
  2. Wähle im OsmAnd-Dialog zwingend „Als Favoriten“ (wählst du „Als Track“, färbt OsmAnd alle Punkte gelb und ignoriert die Gruppen-Ordner).
  3. Kontrolle: Unter Meine Orte → Favoriten erscheinen alle Ebenen (z. B. Geocaching - Traditional, Geocaching - Mystery-Cache) mit deinen gewählten Farben, Formen und Icons.
